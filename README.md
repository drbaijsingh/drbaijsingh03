# Crashworthiness Simulations using LS-DYNA

This repository contains my crashworthiness and occupant safety simulations performed during professional training at Eleno Inc. The work demonstrates explicit dynamic analysis of automotive structures with a focus on energy absorption, deformation modes, intrusion behavior, and regulatory compliance.

---

## Topics Covered

- Seat Belt Anchorage – ECE R14
- Side Impact
- Roof Crush
- Frontal Impact
- Bumper Impact
- Energy Absorption
- Intrusion & Deformation Analysis

---

## Tools Used

- LS-DYNA (Explicit Solver)
- HyperMesh
- LS-PrePost
- ANSA
- MATLAB (Post-processing)

---

## What You Will Find Here

Each case study includes:
- Problem description
- Model setup
- Boundary conditions
- Load cases
- Contour plots
- Animations
- Key observations

---

## Disclaimer

All simulations are created for training, demonstration, and academic purposes only.  
No OEM, proprietary, or confidential data is used.
